# Вклад в проект

## Установка плагина локально

Плагин подключается через `cli.json` — в секцию `plugins` добавьте путь
до каталога плагина:

```jsonc
{
  "plugins": [
    "/home/administrator/.config/opencode/tui/session-tree"
  ]
}
```

Либо положите симлинк на каталог плагина в каталог, который OpenCode
сканирует на предмет локальных плагинов. После перезапуска OpenCode
появится команда `/tree` и секция «Session Tree» в боковой панели.

## Проверка перед отправкой

Обязательны две команды из корня репозитория:

```sh
bun test            # все тесты должны пройти
bunx tsc --noEmit   # ошибок типов быть не должно
```

## Требования к коммитам

- Коммиты — по-русски, короткие и самодостаточные.
- Один коммит — одна логическая единица: не смешивайте фиксы и фичи.
- Не коммитьте `node_modules/` и артефакты сборки.

## Тесты

На любую новую или изменённую логику **обязательно** добавляйте тесты в
`test/*.test.ts` (фреймворк `bun:test`). Тесты должны проверять поведение,
а не реализацию.
