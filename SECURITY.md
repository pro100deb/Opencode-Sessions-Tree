# Безопасность

## Как сообщить об уязвимости

Сообщения об уязвимостях **не** публикуйте в открытых Issues. Используйте
приватный security advisory в GitHub:

1. Откройте репозиторий на GitHub.
2. Перейдите во вкладку **Security** → **New advisory**.
3. Опишите уязвимость и приложите шаги воспроизведения.

Мы ответим в течение разумного срока и согласуем сроки исправления.

## Что плагин не хранит

Плагин **не хранит** секреты: токены, ключи API и пароли. Он работает
только с метаданными сессий OpenCode (названия, пути, время) и не читает
содержимое чатов.

## Логи

Отладочный лог пишется в `/tmp/opencode/session-tree.log`. Файл не содержит
секретов, но может содержать пути к файлам и названия сессий — приложите
его в баг-репорте только при необходимости.
